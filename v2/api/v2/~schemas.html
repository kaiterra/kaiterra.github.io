Organization

A tenant. Every collection the organization owns lives under `/v2/orgs/{org}/`.
id
​string · uuid · required

The organization's ID. Use it as the {org} path segment.

name
​string · required

The organization's display name.

EntityReference

Points at an entity in the organization's hierarchy. It carries only the entity's cheap summary fields.
id
​string · uuid · required

The entity's ID.

type
​string · enum · required

The entity's type.

Enum values:
building
floor
space
hvac_equipment
ext
code
​string · required

The entity's code. It's a short human key, unique among its siblings.

Sensor

A piece of hardware that takes readings.
id
​string · uuid · required

The ID this API uses for the sensor. It's never the serial.

model
​string · required

The sensor's model.

Example: SE-200
serial
​string · required

The number printed on the case.

Example: 0123456789ABCDEF
​object · required

The entity the sensor is placed in.

Example: {"id":"0189b2c0-0000-7000-8000-000000000001","type":"building","code":"HQ"}
​EntityReference[] · required

Every entity above the sensor, root first, ending with the parent.

name
​string · required

The name a user gave the sensor. Empty when it has none.

Example: Lobby

PageResponse

Tells you how to get more items. In cursor mode, only `next_cursor` is present. In offset mode, only `total` is present.
next_cursor
​string | null

If the collection has more items, the value to pass as cursor on your next request. Otherwise, the literal null.

total
​integer

Total number of items in the collection.

SensorListPaged

One page of sensors.
​Sensor[] · required

The sensors on this page.

​object · required

How to get more items. Always present, even when items is empty or this is the last page.

SensorList

The sensors a batch request named. There's no `page`, because the request fixes the number of items.
​Sensor[] · required

One sensor per ID requested, in the order requested.

Problem

An RFC 9457 Problem Details document. Every error response has this shape and is served as `application/problem+json`.
type
​string · uri · required

A URI naming the kind of problem. It's always about:blank, which means the status code is the whole story.

Example: about:blank
title
​string · required

The HTTP reason phrase.

Example: Bad Request
status
​integer · required

The HTTP status code, repeated in the body.

Example: 400
instance
​string · uri · required

This occurrence, as urn:kaiterra:request:<request id>. Quote it when you contact support.

Example: urn:kaiterra:request:a1b2c3d4e5f6
detail
​string

A human-readable explanation of this occurrence. Don't parse it in code.

​ProblemError[]

Field-level detail. Present only on a 400 that is about specific parts of the request.

ProblemError

Names one part of the request and what's wrong with it. Each entry carries either `pointer` or `parameter`, never both.
detail
​string · required

What's wrong with that part of the request.

Example: must be between 1 and 250
pointer
​string

A JSON Pointer into the request body, in URI fragment form, such as #/items/2/parent/id.

parameter
​string

The name of the query or path parameter.

Example: limit
