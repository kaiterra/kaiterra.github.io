Device

Metadata, such as name and firmware version, for a device.
id
​string

Unique ID (UDID) of the device.

name
​string

Friendly name of the device assigned by the owner in the mobile app or dashboard.

model
​string

Model number of the device.

firmware_version
​string

The last reported firmware version of the device.

home_region
​string

Home region of the current device.

​Handshake

Extended metadata reported by the device in its last hourly handshake.

Handshake

Extended metadata reported by the device in its last hourly handshake.
_device_ts
​string

The device's internal clock

dmac_eth
​string

The device's Ethernet MAC address, if applicable. Reported as either dmac_eth or dmac_ethernet.

dmac_ethernet
​string

The device's Ethernet MAC address, if applicable. Reported as either dmac_eth or dmac_ethernet.

dmac_wifi
​string

The device's Wifi MAC address. Reported as either dmac_wifi or dmac.

dmac
​string

The device's Wifi MAC address. Reported as either dmac_wifi or dmac.

dsn
​string

The device's serial number

​SensorModule[]

One entry per installed sensor module. Populated for all device models that report module information (SE-100, SE-200, SE-300).

ts
​string

The timestamp on the server when the handshake was received

sbay102.slifetime
​number · deprecated

Deprecated; use modules instead. The fraction of useful sensor module lifetime remaining (left sensor bay). Only populated for SE-100 and SE-200 devices.

sbay102.stype
​string · deprecated

Deprecated; use modules instead. The model number of the sensor module installed (left sensor bay). Only populated for SE-100 and SE-200 devices.

sbay103.slifetime
​number · deprecated

Deprecated; use modules instead. The fraction of useful sensor module lifetime remaining (right sensor bay). Only populated for SE-100 and SE-200 devices.

sbay103.stype
​string · deprecated

Deprecated; use modules instead. The model number of the sensor module installed (right sensor bay). Only populated for SE-100 and SE-200 devices.

SensorModule

Describes one installed sensor module.
bay
​number · required

The sensor module bay this entry describes. 0 is the left bay, 1 is the right bay.

serial
​string

The serial number of the installed sensor module.

type
​string

The model number of the installed sensor module (for example, KM-103, KM-207, KM-300).

lifetime_pct
​number

The percentage of useful sensor module lifetime remaining, on a 0-100 scale, rounded to 4 significant figures.

SensorReadings

Sensor readings, returned as an array of parameters, with a series of data points under each parameter.
​ParameterSeries[]

SensorReadingsPage

Sensor readings, with an optional link to the next page of data for queries that return large amounts of data.
​ParameterSeries[]
​object

Pagination links, present when the result set is too large to fit into a single response.

ParameterSeries

A series of data points for a single measured parameter.
param
​string

The parameter code. See the Sensor Reading Data Format guide for the list of parameter codes.

units
​string

The units under which the parameter is expressed. See the Sensor Reading Data Format guide for the list of unit codes.

source
​string

(Present for sensor modules) The module that captured the parameter reading. For instance, km102 identifies the KM-102 sensor module.

span
​number

The sampling interval, in seconds, over which this measurement was taken. For example, 60 refers to a sample taken over the span of one minute, and 3600 designates hourly averages.

​DataPoint[]

The actual array of data points for this series. Even if the series has only one data point, this is still an array.

DataPoint

A single measurement in a parameter series.
ts
​string

Timestamp marking the end of the sampling interval, in RFC3339 format (UTC).

value
​number | null

The measured value. May be null if data is unavailable for this data point.

BatchSubRequest

One request within a batch.
method
​string · required

The HTTP method to use.

relative_url
​string · required

The URL to request, relative to the Kaiterra API's base URL.

​object[]

A JSON array of header description objects, each of which has a name and value object.

body
​string

The request body for this request. JSON objects must be JSON-encoded before being placed in this string.

BatchSubResponse

The result of one request within a batch.
code
​integer

The HTTP status code returned by this sub-request.

body
​string

The response body of this sub-request, returned as a JSON string.
